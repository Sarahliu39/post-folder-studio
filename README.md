# Post Folder Studio

A macOS app for organizing post-production folders and bins.

为影视后期建立清晰、可交接的项目目录。

[下载最新版](https://github.com/Sarahliu39/post-folder-studio/releases/latest) · [反馈问题](https://github.com/Sarahliu39/post-folder-studio/issues)

## 主要功能

- 内置后期项目目录模板，支持拍摄天数、机位数及可选模块。
- 可编辑目录预览：新增、重命名、删除节点后再生成文件夹。
- 保存个人模板，导入和导出 JSON 模板。
- 中英文界面及双语目录命名。
- 连接已打开的 DaVinci Resolve 项目并创建媒体池 Bin。
- 日夜主题、多套配色、玻璃／磨砂／纯色材质与透明度设置。

## 下载与安装

从 Releases 下载 DMG，打开后将 Post Folder Studio.app 拖入 Applications。

系统要求：Apple Silicon（M 系列）Mac，macOS 13 或更新版本。当前未提供 Intel Mac 或 Windows 安装包。此包尚未经过 Apple Developer ID 签名与公证，首次打开可能提示无法验证开发者。

## 快速开始

输入项目名称 → 选择模板 → 设置天数和机位 → 检查目录预览 → 选择位置并生成文件夹。

创建 Resolve Bin 前，请打开目标项目并启用本地脚本访问；可用性取决于 Resolve 版本和脚本配置。

## English

Post Folder Studio organizes post-production folders using editable presets, shooting-day and camera settings, and reusable templates. It also creates media-pool bins in an open DaVinci Resolve project.

Download the DMG from Releases and drag the app into Applications. Requires Apple Silicon and macOS 13+. This build is not notarized by Apple. Starting with 5.0.0, Sparkle supports in-app download, signature verification, installation and relaunch. Older builds without the updater need one manual installation first.
